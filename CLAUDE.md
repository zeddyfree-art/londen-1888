# Werkafspraken

- Na elke aanpassing: meteen een pull request maken naar de standaardbranch (`claude/charming-franklin-2x9p2x`) en die zelf mergen. De workflow zet de app daarna online.
- Bij elke update die spelers merken: een nieuw bericht bovenaan `data/nieuws.json` (hoger `id`) en een regel in `ontwerp/te-doen.md`.
- Alle teksten in het spel zijn Nederlands.
